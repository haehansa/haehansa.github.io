Now, let’s look at the source code from the app.py file.

{% codeblock lang:python mark:36-38,42 %}
from flask import Flask, request, jsonify, send_file, render_template, redirect, url_for, Response
import os
import json
from uuid import uuid4

app = Flask(name)

TICKETS_DIR = “tickets”

if not os.path.exists(TICKETS_DIR):
os.makedirs(TICKETS_DIR)

@app.route(‘/‘)
def index():
return render_template(‘index.html’)

@app.route(‘/book’, methods=[‘POST’])
def book_ticket():
data = {
“name”: request.form[‘name’],
“email”: request.form[‘email’],
“phone”: request.form[‘phone’],
“date”: request.form[‘date’],
“cabin”: request.form[‘cabin’]
}

ticket_id = str(uuid4())
json_filename = f"{ticket_id}.json"
json_filepath = os.path.join(TICKETS_DIR, json_filename)

with open(json_filepath, 'w') as json_file:
    json.dump(data, json_file)

return redirect(url_for('download_ticket', ticket=json_filename))

@app.route(‘/download’, methods=[‘GET’])
def download_ticket():
ticket = request.args.get(‘ticket’)
if not ticket:
return jsonify({“error”: “Ticket parameter is required”}), 400

json_filepath = os.path.join(TICKETS_DIR, ticket)

if os.path.exists(json_filepath):
    return send_file(json_filepath, as_attachment=True, download_name=ticket)
else:
    return jsonify({"error": "Ticket not found"}), 404

if name == ‘main‘:
app.run(host=’127.0.0.1’, port=5000)
{% endcodeblock %}

This code creates a web application that allows users to book tickets by filling out a form. The ticket information is saved as a JSON file in the “tickets” directory, and users can download their tickets after booking.
However, there is a vulnerability in line 38 and line 42. The ticket value is not properly validated, allowing hackers to exploit the LFI vulnerability.

So we can read any system file (provided the current user has read permission) easily.
